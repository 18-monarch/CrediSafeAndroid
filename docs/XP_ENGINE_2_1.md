# CrediSafe XP Engine 2.1

This Android engine is aligned with the web XP Engine 2.0 rules while adding mobile telemetry-quality and anti-gaming gates.

## Awards
- Valid trip completion: +25 XP
- Safety score: +5 to +110 XP
- Validated distance: 2 XP/km, capped at 50 XP
- Clean trip: +25 XP
- Trusted GPS: +8 or +15 XP
- Streak: +5 to +25 XP, once per day
- Per-trip cap: 220 XP

## Eligibility
A real trip must cover at least 0.5 km, last at least 2 minutes, and reach at least 35% GPS confidence.

The Android pilot also blocks XP when telemetry contains anomaly flags such as suspicious GPS jumps or very low telemetry quality.

## Reward points
Eligible real trips convert 50% of awarded XP into spendable reward points. Lifetime XP remains the progression/leaderboard currency.

## Transparency
The Android database stores a JSON XP breakdown on every completed trip, including every component, eligibility reason, anti-gaming flags and engine version.
