# CrediSafe Android 2.3 — XP Engine + Telematics Upgrade

This is a drop-in source update for the working CrediSafe Android pilot.

## What changed

### XP Engine 2.1
Aligned to the CrediSafe web XP Engine 2.0:
- +25 completion
- +5..110 safety score
- 2 XP/km capped at 50
- +25 clean trip
- +8/+15 trusted GPS
- +5..25 daily streak
- 220 XP per-trip cap
- 0 XP for ineligible real trips
- 50% XP -> reward points on eligible real trips
- full JSON breakdown persisted on the trip
- anti-gaming / telemetry-quality gate
- engine version persisted

### Telematics 2.1
- fused GNSS with filtered segment validation
- accelerometer + gyroscope + linear acceleration + rotation vector
- world-frame motion transformation
- vehicle-frame longitudinal/lateral acceleration using GPS bearing
- approximately 10 Hz persisted research telemetry
- batched SQLite sensor writes
- event cooldowns
- GPS quality scoring
- sensor quality scoring
- suspicious-jump detection
- Android mock-location detection
- harsh braking / acceleration / cornering detection with confidence
- telemetry quality score

### Database
Migrates v1 -> v3 automatically.
Adds:
- XP breakdown JSON
- eligibility reason
- telemetry quality
- anti-gaming flags
- vertical acceleration
- longitudinal/lateral jerk
- event detail
- indexes for trip-time queries

## Build on Windows

From the Android project root:

```powershell
.\gradlew.bat clean test assembleDebug
```

Do not uninstall the existing app. The database migration is designed to upgrade the existing database in place.

## Calibration principle

The thresholds are pilot defaults, not certified safety thresholds. Keep them centralized in `TelematicsConfig.kt` and recalibrate from labelled real-world driving data before treating the resulting safety score as a production safety/insurance metric.


## Package version
`versionCode=21`, `versionName=2.3.0` so it can upgrade the existing pilot installation with version 20.
